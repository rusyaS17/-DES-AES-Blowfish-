# Symmetric Encryption Lab — Web

Бұл нұсқа Python/Streamlit қажет етпейді.

## Ашудың ең оңай жолы

1. `index.html` файлын VS Code-та аш.
2. Егер Live Server extension орнатылған болса:
   - файлды аш;
   - төменгі оң жақтағы **Go Live** батырмасын бас.
3. Немесе `index.html` файлын браузерге сүйреп апарып аш.

> Сайт AES-128, DES және Blowfish үшін браузерде CryptoJS кітапханасын CDN арқылы жүктейді, сондықтан алғашқы ашқанда интернет қосулы болуы керек.

## Қолдану

- Алгоритмді таңда.
- Шифрлау немесе дешифрлауды таңда.
- Мәтін мен кілтті енгіз.
- `🚀 ШИФРЛАУ` / `🚀 ДЕШИФРЛАУ` бас.
- Base64 және HEX нәтижесін көр.
- `Қадамдар`, `Схема`, `Код логикасы` бөлімдерін қара.

Бұл оқу/демонстрациялық жоба.
